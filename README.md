# Portfolio Website - Krish Kumar Kumawat

A modern, minimalist portfolio website built with Next.js, React, and Tailwind CSS featuring a dark tech theme.

## 🎨 Features

- **Minimalist Dark Tech Theme** - Clean, modern design with cyan accents
- **Responsive Design** - Works perfectly on mobile, tablet, and desktop
- **Smooth Animations** - Framer Motion animations for engaging interactions
- **Fast Performance** - Built with Next.js for optimal speed
- **SEO Optimized** - Meta tags and structured data
- **Mobile Friendly** - Navigation menu and responsive layout

## 📋 Sections

1. **Hero** - Eye-catching introduction
2. **About** - Personal information, education, and interests
3. **Skills** - Programming, soft skills, and interests
4. **Achievements** - Award-winning game development project
5. **Contact** - Email, phone, and social media links
6. **Footer** - Credits and navigation

## 🛠️ Tech Stack

- **Framework**: Next.js 14
- **Language**: JavaScript/React
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Icons**: Lucide React

## 📦 Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/jhaprashant11/krish.git
   cd krish
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📝 Customization

To update personal information, edit the components in the `components/` directory:

- `components/Hero.jsx` - Main heading and introduction
- `components/About.jsx` - Personal details and hobbies
- `components/Skills.jsx` - Technical and soft skills
- `components/Achievements.jsx` - Award and certification info
- `components/Contact.jsx` - Contact information and social links

## 🚀 Deployment

Deploy on Vercel (recommended):

1. Push your code to GitHub
2. Go to [Vercel](https://vercel.com)
3. Import your repository
4. Click Deploy
